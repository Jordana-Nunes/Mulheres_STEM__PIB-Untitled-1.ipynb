Participação Feminina vs. Economia Mundial
Este projeto utiliza Python e a API do Banco Mundial para analisar como a presença de mulheres no mercado de trabalho impacta a riqueza das nações.

O Problema:
Muitas vezes discute-se a importância da diversidade de gênero apenas sob o ponto de vista social. Este projeto traz o ponto de vista econômico, provando estatisticamente a relação entre inclusão e aumento do PIB.

O que o código faz:
Consumo de API: Busca dados em tempo real do Banco Mundial.

Data Cleaning: 
Limpa e cruza dados de PIB e Força de Trabalho de mais de 180 países.

Visualização de Dados: Gráfico de Regressão: Mostra a tendência de crescimento.
  - Série Temporal: Exibe a evolução global desde 2010.
  - Mapa Interativo: Um mapa-múndi onde você pode ver os índices de cada país ao passar o mouse.

Para visualizar:
  - Basta rodar o script para gerar:
      Um arquivo .csv pronto para Excel/Power BI.
      Gráficos dinâmicos que mostram o "porquê" de investir em equidade de gênero.
